# 한라초 홍보글 작성 — 데스크톱 앱

학교 홈페이지 알림마당(공지사항·학교소식)에 올릴 홍보글 초안을 만드는 프로그램입니다.
Google Apps Script 웹앱이던 것을 **내 컴퓨터에 설치해서 쓰는 앱**으로 옮긴 것입니다.
화면과 글 만드는 방식은 그대로이고, Apps Script 프로젝트·배포·스크립트 속성 설정이 필요 없어졌습니다.

- Windows(설치판·무설치판)와 macOS를 지원합니다.
- API 키는 앱의 **설정** 창에 한 번만 넣으면 됩니다. 키는 내 컴퓨터에만 저장됩니다.
- 만든 글은 자동으로 **보관함**에 텍스트 파일로 남습니다.
- 홍보글 예시·규칙은 앱을 다시 만들지 않고 **메모장으로 고칠 수 있습니다.**

---

## 1. 준비물

- Anthropic API 키 (결제 수단 등록 필요, 선불 충전 방식 5달러부터)
  1. `console.anthropic.com` 접속 후 로그인
  2. Billing 메뉴에서 결제 수단 등록
  3. API Keys 메뉴 > Create Key > 이름은 아무거나 (예: 한라초홍보글)
  4. **키는 이 화면에서만 보입니다.** 복사해 두세요.

---

## 2. 설치

### Windows

1. 설치 파일을 내려받습니다. (아래 **4. 설치 파일 구하기** 참고)
   - `한라초 홍보글 작성-1.0.0-win-x64.exe` — 설치판. 바탕화면과 시작 메뉴에 바로가기가 생깁니다.
   - `한라초 홍보글 작성-1.0.0-무설치.exe` — 무설치판. 아무 폴더에 두고 더블클릭하면 됩니다.
2. 실행하면 **"Windows의 PC 보호"** 파란 창이 뜰 수 있습니다.
   → **추가 정보** > **실행** 을 누릅니다. (인증서로 서명하지 않은 개인 제작 프로그램이라 뜨는 정상적인 경고입니다.)

### macOS

1. `한라초 홍보글 작성-1.0.0-mac-universal.dmg` 를 열고 앱을 **응용 프로그램** 폴더로 끌어 넣습니다.
2. 처음 실행할 때 "확인되지 않은 개발자" 또는 "손상되었기 때문에 열 수 없습니다"가 뜨면
   앱을 **우클릭 > 열기** 하거나, 터미널에서 아래를 한 번 실행합니다.
   ```
   xattr -cr "/Applications/한라초 홍보글 작성.app"
   ```

---

## 3. 처음 실행

1. 앱을 켜면 **설정** 창이 먼저 뜹니다.
2. **Anthropic API 키** 칸에 복사해 둔 키를 붙여 넣고 **저장**을 누릅니다.
3. 끝입니다. 왼쪽에 활동을 적고 **홍보글 만들기**를 누르세요.

- 설정은 오른쪽 위 **⚙ 설정** 버튼이나 메뉴 **파일 > 설정…** (Ctrl+,)으로 다시 열 수 있습니다.
- 모델은 기본값(Claude Sonnet 5)을 권장합니다. 더 아끼려면 Haiku, 더 정교하게 쓰려면 Opus를 고르면 됩니다.
- 키는 Windows 자격 증명 보호(DPAPI) 또는 macOS 키체인으로 암호화되어 이 컴퓨터에만 저장됩니다.
  설정 창의 **저장된 키 삭제**로 언제든 지울 수 있습니다.

---

## 4. 설치 파일 구하기

설치 파일은 GitHub Actions가 만들어 줍니다. (소스만 있으면 누구나 같은 파일을 다시 만들 수 있습니다.)

**방법 A — 바로 만들기**
1. GitHub 저장소 > **Actions** > 왼쪽 목록에서 **한라초 홍보글 작성 앱 빌드**
2. 오른쪽 **Run workflow** > 운영체제 선택(windows / mac / both) > **Run workflow**
3. 5~10분 뒤 실행이 끝나면, 그 실행 페이지 맨 아래 **Artifacts**에서 `windows` 을 내려받아 압축을 풉니다.

**방법 B — Releases 에 올려 두기**
`promo-v1.0.0` 같은 태그를 붙여 푸시하면 Windows·macOS 파일이 모두 만들어져 **Releases** 페이지에 올라갑니다.
```
git tag promo-v1.0.0
git push origin promo-v1.0.0
```

**방법 C — 내 컴퓨터에서 직접 만들기** (Node.js 20 이상 필요)
```
cd halla-promo-writer
npm install
npm run dist:win      # Windows 에서 실행 → dist/ 폴더에 .exe
npm run dist:mac      # macOS 에서 실행 → dist/ 폴더에 .dmg
```

## 5. 쓰면서 알아둘 것

**비용**
글 한 편에 대략 40~60원(기본 모델 기준)입니다. 만든 뒤 화면 아래에 이번 글의 토큰 수와 어림 비용이 표시됩니다.
같은 규칙·예시를 매번 보내므로 이를 캐시하도록 해 두었습니다. **5분 안에 "다시 쓰기"를 누르면 입력 비용이 크게 줄어듭니다.**
사용량과 잔액은 메뉴 **도움말 > 사용량·결제 확인**에서 볼 수 있습니다.

**개인정보**
학생 이름, 학부모 이름, 강사 실명은 되도록 넣지 말고 빈칸으로 글을 만든 뒤 완성본에 직접 채워 넣으세요.

**꼭 확인할 것**
날짜, 인원, 학급 수, 시수, 기관명, 수상 내역. AI가 그럴듯하게 지어내기 쉬운 항목입니다.

**만든 글 보관함**
만든 글은 자동으로 텍스트 파일로 저장됩니다. 메뉴 **파일 > 만든 글 보관함 열기**.

## 6. 예시·규칙 고치기 (앱을 다시 만들 필요 없음)

새로운 유형의 홍보글을 쓰게 되면 메뉴 **도움말 > 홍보글 예시 편집…** 을 누르세요.
예시가 담긴 텍스트 파일이 메모장으로 열립니다. 맨 아래에 같은 형식으로 덧붙이고 저장하면 **다음 글부터 바로 반영**됩니다.

```
─── 어떤 유형인지 한 줄 설명 ───
제목: (제목)
□ (첫 문단)

□ (둘째 문단)
```

- Apps Script 때와 달리 따옴표나 쉼표를 붙일 필요가 없습니다. 글을 그대로 붙여 넣으면 됩니다.
- 유형 사이는 빈 줄 한 줄로 띄웁니다.
- 비슷한 유형을 늘리는 것보다 **없던 유형을 하나 채우는 쪽**이 효과가 큽니다. 예시가 많아지면 비용도 조금씩 오르니 겹치는 것은 지워도 됩니다.
- 교장 성함 등 규칙을 바꾸려면 **도움말 > 작성 규칙 편집…**.
- 잘못 고쳤으면 **도움말 > 기본 예시·규칙으로 되돌리기**.

파일 위치: Windows `C:\Users\<이름>\AppData\Roaming\HallaPromoWriter\prompt\`, macOS `~/Library/Application Support/HallaPromoWriter/prompt/`

---

## 7. 다음 담당자에게 넘길 때

1. 설치 파일(또는 이 저장소 주소)과 이 안내서를 전달합니다.
2. 새 담당자가 본인 API 키를 발급받아 **설정 창에 넣습니다.**
3. 직접 고친 예시·규칙 파일이 있으면 위 `prompt` 폴더째 복사해 줍니다.

API 키는 발급받은 사람 결제에 묶여 있으니, 넘기기 전에 이전 키는 콘솔에서 삭제하고 앱의 **저장된 키 삭제**도 눌러 주세요.

## 개발자용 메모

```
halla-promo-writer/
  src/main.js         창·메뉴·IPC·보관함 (Electron 메인 프로세스)
  src/preload.js      화면에 window.halla 만 노출
  src/api.js          Anthropic API 호출, 입력 조립, 오류 안내문 (Electron 비의존)
  src/prompt.js       내장 규칙·예시 (옛 Prompt.gs)
  src/promptStore.js  사용자 예시·규칙 파일(userData/prompt/) 읽기·만들기·되돌리기
  src/settings.js     API 키(safeStorage 암호화)·모델 저장
  renderer/           화면 (index.html, style.css, app.js — 옛 Index.html)
  test/               node:test 단위 테스트 (가짜 Anthropic 서버 포함)
  build/icon.png      앱 아이콘
```

```
npm install
npm start        # 개발 실행
npm test         # 단위 테스트
npm run dist     # 현재 운영체제용 설치 파일 만들기
```

- 개발 중에는 환경 변수 `ANTHROPIC_API_KEY`가 있으면 저장된 키보다 우선합니다.
- `ANTHROPIC_BASE_URL`을 주면 가짜 서버로 붙일 수 있습니다(테스트용).
- 모델 목록·가격은 `src/api.js`의 `MODELS`에 있습니다.
