# Apps Script 판 (이전 버전 · 참고용)

데스크톱 앱으로 옮기기 전, Google Apps Script 웹앱으로 쓰던 원본 파일입니다.
학교에서 아직 Apps Script 배포본을 쓰고 있다면 그대로 두어도 되고, 설치 방법은 `설치안내.md`에 있습니다.

| 파일 | 데스크톱 앱에서의 위치 |
|---|---|
| `Code.gs` (API 호출, 입력 조립) | `../src/api.js`, `../src/main.js` |
| `Prompt.gs` (규칙·예시) | `../src/prompt.js` — 앱에서는 텍스트 파일로도 고칠 수 있음 |
| `Index.html` (화면) | `../renderer/` |

규칙·예시를 고칠 때 두 판을 같이 쓰고 있다면 양쪽 모두 반영해야 합니다.
