# 한라초 홍보글 작성 — 설치 안내

## 준비물
- 구글 계정 (교육청 계정은 관리자가 Apps Script 배포를 막아둔 경우가 있으니 **개인 Gmail 권장**)
- Anthropic API 키 (결제 수단 등록 필요)

---

## 1. API 키 발급

1. `console.anthropic.com` 접속 후 로그인
2. Billing 메뉴에서 결제 수단 등록 (선불 충전 방식, 5달러부터 가능)
3. API Keys 메뉴 > Create Key > 이름은 아무거나 (예: 한라초홍보글)
4. **키는 이 화면에서만 보입니다.** 메모장에 복사해 두세요.

---

## 2. Apps Script 프로젝트 만들기

1. `script.google.com` 접속 > 좌측 상단 **새 프로젝트**
2. 프로젝트 이름을 `한라초 홍보글 작성`으로 변경
3. 파일 3개를 아래처럼 만듭니다.

| 파일 | 만드는 법 | 붙여넣을 내용 |
|---|---|---|
| `Code.gs` | 기본으로 있음 (내용 전체 지우고 덮어쓰기) | Code.gs |
| `Prompt.gs` | 좌측 **파일 +** > 스크립트 > 이름 `Prompt` | Prompt.gs |
| `Index.html` | 좌측 **파일 +** > **HTML** > 이름 `Index` | Index.html |

> HTML 파일은 반드시 '스크립트'가 아니라 'HTML'로 만들어야 합니다.
> 파일 이름에 확장자는 붙이지 않습니다. `Index`라고만 쓰면 됩니다.

4. 저장 (Ctrl+S)

---

## 3. API 키 넣기

1. 좌측 **톱니바퀴(프로젝트 설정)** 클릭
2. 맨 아래 **스크립트 속성** > **스크립트 속성 추가**
3. 속성: `ANTHROPIC_API_KEY` / 값: 아까 복사한 키
4. **스크립트 속성 저장**

> 코드 안에 키를 직접 적지 마세요. 여기에 넣으면 화면 쪽으로 노출되지 않습니다.

---

## 4. 배포

1. 우측 상단 **배포** > **새 배포**
2. 톱니바퀴 > **웹 앱** 선택
3. 설정
   - 설명: `1차 배포`
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **나만** (혼자 쓸 때) 또는 **링크가 있는 모든 Google 계정 사용자** (동학년 공유)
4. **배포** > 권한 승인 요청이 뜨면 **액세스 승인**
5. "이 앱은 Google에서 확인하지 않았습니다" 경고 → **고급** > **한라초 홍보글 작성(안전하지 않음)으로 이동**
   - 본인이 만든 앱이라 뜨는 정상적인 경고입니다.
6. 나오는 **웹 앱 URL**을 북마크에 저장

끝났습니다. 이제 그 주소로 들어가면 됩니다.

---

## 쓰면서 알아둘 것

**비용**
글 한 편에 대략 40~60원입니다. 5달러 충전하면 100편 넘게 쓸 수 있습니다.
더 아끼려면 `Code.gs` 맨 위 `MODEL`을 `'claude-haiku-4-5-20251001'`로 바꾸세요. 값은 1/3 정도로 줄지만 문장이 조금 단조로워집니다.

**개인정보**
학생 이름, 학부모 이름, 강사 실명은 되도록 넣지 말고 빈칸으로 글을 만든 뒤 완성본에 직접 채워 넣으세요.

**꼭 확인할 것**
날짜, 인원, 학급 수, 시수, 기관명, 수상 내역. AI가 그럴듯하게 지어내기 쉬운 항목입니다.

## 예시 추가하기

새로운 유형의 홍보글을 쓰게 되면 `Prompt.gs`의 `EXAMPLES` 배열 맨 아래에 같은 형식으로 덧붙이면 됩니다.

```javascript
'',
'─── 어떤 유형인지 한 줄 설명 ───',
'제목: (제목)',
'□ (첫 문단)',
'',
'□ (둘째 문단)',
```

- 각 줄은 따옴표로 감싸고 끝에 쉼표를 붙입니다.
- 문단 사이 빈 줄은 `'',` 한 줄로 넣습니다.
- 본문에 작은따옴표가 있으면 `\'` 로 씁니다. (예: `'\'마음수업\''`)
- 마지막 줄에는 쉼표를 붙이지 않습니다.

비슷한 유형을 늘리는 것보다 **없던 유형을 하나 채우는 쪽**이 효과가 큽니다.
예시가 많아지면 비용도 조금씩 오르니, 겹치는 것은 지워도 됩니다.

수정한 뒤에는 **배포 > 배포 관리 > 연필 아이콘 > 버전: 새 버전 > 배포**를 해야 반영됩니다.
