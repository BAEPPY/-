# 웹캠 녹화기

설치 없이 브라우저에서 바로 쓰는 웹캠 녹화 프로그램입니다. 파일 하나(`index.html`)로 동작하며, 영상은 서버로 전송되지 않고 내 컴퓨터 안에서만 처리됩니다.

## 실행

- `index.html` 을 Chrome / Edge / Firefox 에서 더블클릭해 열기
- 또는 로컬 서버로 열기: `npx serve webcam-recorder` → http://localhost:3000

> 카메라는 보안상 `https://`, `http://localhost`, `file://` 에서만 열립니다.

## 기능

- 카메라·마이크 선택, 해상도 선택 (480p ~ 4K), 오디오 끄기
- 녹화 / 일시정지 / 다시 시작 / 중지, 녹화 시간 표시
- 녹화 형식 선택 (브라우저가 지원하는 WebM VP9·VP8, MP4 중에서)
- 마이크 입력 레벨 표시
- 사진 찍기 (PNG)
- 녹화 목록에서 바로 재생, 다운로드, 삭제

## 단축키

| 키 | 동작 |
|---|---|
| Space | 녹화 시작 / 중지 |
| P | 일시정지 / 다시 시작 |
| S | 사진 찍기 |

녹화 목록은 페이지를 닫으면 사라지므로 필요한 파일은 **다운로드**해 두세요.
